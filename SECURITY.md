# Security Policy

Risk assessment is performed on the current `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < v0.1  | :x:                |

## Reporting a Vulnerability

MuseumSpark is currently a static site backed by generated JSON data, with a future API planned for a later phase.

If you discover a security vulnerability, such as an XSS issue in the browse page or a data injection issue, please do not open a public issue.

Instead, email **<mark.hazleton@gmail.com>** or use the repository owner's public contact path. We will review and respond promptly.
