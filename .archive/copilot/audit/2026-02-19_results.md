## Root Cause Analysis

The widespread schema validation failures indicate that pipeline enrichment scripts are outputting values not aligned with the JSON schema:

1. **Status field**: Some enrichment phase is setting `"Active"` (capitalized) instead of `"active"` (lowercase)
2. **Time needed field**: Phase 1.9 planner metadata is outputting verbose format `"Half day (2-4 hours)"` instead of schema-compliant `"Half day"`
3. **Scored by field**: Phase 2 scoring is recording the model name `"gpt-4o-mini"` instead of the controlled vocabulary value `"assistant"`

**Recommended Fix**: Update the enrichment pipeline phases to output schema-compliant values, then run a one-time data migration.
